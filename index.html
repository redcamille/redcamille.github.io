wBundle™

Convert, merge, organize, and split PDF, Microsoft Office, and Visio documents with Windows Explorer integration.

Overview

wBundle™ is a Windows 10 22H2 x64 (build 19045) and Windows 11 x64 utility for converting, merging, organizing, and splitting PDF and Microsoft Office documents.

Features

  • Merge PDF, Word, Excel, PowerPoint, and Visio files into one PDF Bundle
  • Convert selected Word, Excel, PowerPoint, and Visio documents into individual PDFs
  • Accept .zip selections as a supported format: inspect ZIP metadata without extracting, then extract after Start into a per-run temporary directory
  • Generate filename bookmarks and patent-file-wrapper bookmark colors
  • Choose Document Start Mode for merged Bundles: Continuous or Odd Page Start
  • Convert a single selected PDF: detect FW from bookmark titles, report Natural Sort or EP/US date bookmark order, optionally reorder top-level or second-level page blocks, and apply FW coloring
  • Split a single selected PDF at bookmark then page boundaries using a Maximum Words per PDF limit
  • Name Splitter Parts as [OutputFilename]_PartN_pStart-End_chStart-End, using printed page ranges and chapter IDs
  • Insert a selectable-text summary page at the start of each Splitter Part and remap Bookmarks after that page
  • Integrate with the Windows Explorer legacy context menu for selected files
  • Integrate with the Windows Explorer Send to menu for all users

Installation & Location

Installed per-machine to the native 64-bit Program Files folder:

C:\Program Files\wooBundle\

The installer creates or updates the Windows Explorer context-menu entry, the all-users Send to shortcut, and a Start Menu shortcut used so Windows can attribute Action Center notifications. The context-menu command is registered for files only, not for folders or folder backgrounds.

Supported Input Extensions

  • PDF: .pdf
  • Word: .doc, .docx, .docm, .dot, .dotx
  • Text/HTML: .txt, .rtf, .odt, .html, .htm, .mht
  • Excel: .xlsx, .xls, .xlsm, .xlsb, .ods, .csv
  • PowerPoint: .ppt, .pptx, .pptm, .pps, .ppsx, .ppsm, .odp, .potx, .potm, .pot
  • Visio: .vsd, .vsdx
  • ZIP: .zip (selection format only; members must be supported document types)

Usage

  1. Select one or more supported files in Windows Explorer.
  2. Right-click and select wBundle™. On Windows 11, select Show more options when necessary. Alternatively, right-click and choose Send to → wBundle™.
  3. Configure the input screen for the current selection. Mode is based on files after ZIP expansion; a ZIP itself is not a processing input:
    • Two or more files, One merged PDF Bundle: Output Mode, Bookmark Type, Filename Sort Order, Document Start Mode, Output Filename, Output Folder.
    • Two or more files, Individual PDFs: Output Mode and Output Folder.
    • Exactly one non-PDF file: Output Filename and Output Folder only (One merged PDF Bundle, Original Only, Ascending).
    • Exactly one PDF, Converter: Processing Mode, Current Bookmark Order, Bookmark Sort Order, Output Filename, Output Folder.
    • Exactly one PDF, Splitter: Processing Mode, Current Bookmark Order, Maximum Words per PDF, Output Filename, Output Folder.
  4. Select Start. ZIP members are extracted only after Start.

Output Naming Rules

Merged FW: [CurrentFolderName]__fw.pdf
Other Merged: [CurrentFolderName].pdf
Blank Merged: wooBundle.pdf
Individual Files: [Filename].pdf (smallest numeric suffix)
Splitter Parts: [OutputFilename]_PartN_pStart-End_chStart-End.pdf

Known Limitations

  • All selected files must be in the same folder.
  • Explorer context-menu processing supports at most 100 selected files, and at most 100 processing files after ZIP expansion.
  • Send to selection size is limited by the Windows command-line length.
  • A ZIP is not converted or merged as a document. Nested ZIP members are unsupported. Unreadable, empty, encrypted, or unsafe ZIPs are rejected.
  • Password-protected PDFs requiring user credentials are not supported.
  • Damaged, protected, or interactive Office documents may fail conversion.
  • Office documents are opened with macros disabled.
  • .odp conversion requires PowerPoint OpenDocument support.
  • .ods conversion requires Excel OpenDocument support.
  • .csv conversion uses Microsoft Excel. Delimiter, encoding, and text-import behavior are determined by Excel.
  • Wide Excel worksheets that need A2 may briefly set the Windows default printer to Adobe PDF when that printer is installed; the previous default is restored afterward. Without Adobe PDF (or equivalent A2 support), conversion continues with a smaller paper size or stronger shrink.
  • .vsd and .vsdx conversion requires Microsoft Visio.
  • .xlsx and .xlsm workbooks containing Excel 4.0 macro sheets are rejected.
  • Advanced PDF bookmark or annotation properties unsupported by pypdf may not be preserved.

wIEEE™

Group IEEE Mentor contribution files into searchable PDF Bundles with auto-generated TOC and Separators.

Overview

wIEEE™ is a Windows 10 22H2 x64 (build 19045) and Windows 11 x64 utility that groups IEEE Mentor contribution files into searchable PDF Bundles with a generated Table of Contents, Separator pages, bookmarks, manifests, and error logs.

Features

  • Convert Word, Text/HTML, Excel, PowerPoint, and Visio files to PDF using Microsoft Office or Visio
  • Set Bundle Target Count on the Home screen (default 20 for the current run; the value is not saved)
  • Group documents by Standard and Year without splitting a DCN group
  • Generate A4 searchable TOC and Separator pages with bundled Unicode fonts
  • Title the TOC as IEEE 802.{Standard} Contribution Bundle : {StartDCN} - {EndDCN}
  • Place a TOC bookmark as the first outline entry, with contribution bookmarks unchanged below it
  • Create contribution bookmarks and full-row TOC links to each Separator
  • Allow only one wooIEEE instance per Windows user session

Installation & Launch

Installed per-machine to the native 64-bit Program Files folder:

C:\Program Files\wooIEEE\

The installer creates a Start Menu shortcut named wIEEE™, including the Application User Model ID used for Action Center notifications. It does not add a Windows Explorer context-menu entry.

Supported Input Extensions

  • PDF: .pdf
  • Word: .doc, .docx, .docm, .dot, .dotx
  • Text/HTML: .txt, .rtf, .odt, .html, .htm, .mht
  • Excel: .xlsx, .xls, .xlsm, .xlsb, .ods, .csv
  • PowerPoint: .ppt, .pptx, .pptm, .pps, .ppsx, .ppsm, .odp, .potx, .potm, .pot
  • Visio: .vsd, .vsdx

Usage

  1. Start wIEEE™ from the Start Menu.
  2. Confirm the Input Folder. The last Browse-selected folder is restored when it still exists; otherwise the Windows Downloads folder is used when present.
  3. Set Bundle Target Count if needed. Each launch starts at 20. The value must be an integer of 1 or greater.
  4. Select Start.
  5. If unsupported files are listed, choose Process only supported files or Cancel.
  6. After completion, use Open Folder to open the Output Folder.

Output Folder & Naming Rules

Results are written to {InputFolder}\wooieee_v0.2.1_output.

Directories whose names start with wooieee, and directories named temp or logs, are excluded from input discovery together with their descendants. Copied Bundle PDFs or manifests that are not under an excluded directory are treated as ordinary input files and can produce Filename Errors.

Bundle PDF: Bundle_[Standard]-[YY]-[StartDCN]-[EndDCN].pdf
Manifest CSV: Bundle_[Standard]-[YY]-[StartDCN]-[EndDCN]_manifest.csv

First collision uses (2), then (3), and so on for both the PDF and matching manifest pair.

Known Limitations

  • Existing wooIEEE outputs are auto-excluded only under directories whose names start with wooieee.
  • Password-protected PDFs requiring user credentials are not supported.
  • Damaged, protected, or interactive Office documents may fail conversion.
  • Office documents are opened with macros disabled and without Office-generated PDF bookmarks.
  • .odp conversion requires PowerPoint OpenDocument support.
  • .ods conversion requires Excel OpenDocument support.
  • .csv conversion uses Microsoft Excel. Delimiter, encoding, and text-import behavior are determined by Excel.
  • Wide Excel worksheets that need A2 may briefly set the Windows default printer to Adobe PDF when that printer is installed; the previous default is restored afterward. Without Adobe PDF (or equivalent A2 support), conversion continues with a smaller paper size or stronger shrink.
  • .vsd and .vsdx conversion requires Microsoft Visio.
  • Characters that the bundled Noto Sans / Noto Sans KR fonts cannot draw are treated as a fatal error.
  • Complex named destinations, external-file actions, or advanced annotations may be lost where pypdf cannot preserve them.
  • The installer does not force-terminate wooIEEE or Microsoft Office. If a running instance does not exit after a graceful-shutdown request, update or uninstall is aborted.
  • Silent or very silent install, update, and uninstall are not supported when a running wooIEEE instance must be closed automatically.

wNurse™

Build, optimize, and validate monthly nurse ward rosters with Google OR-Tools CP-SAT and Excel integration.

Overview

wNurse™ is a Windows desktop app for building and checking monthly nurse ward rosters.

Features

  • Store nurses, staffing, OFF requests, and holidays in a local SQLite database
  • Generate monthly schedules with Google OR-Tools CP-SAT (four candidate profiles)
  • Validate generated and uploaded Excel rosters
  • Export schedules to Excel

Installation & Data Storage

Installed per-machine to the native 64-bit Program Files folder:

C:\Program Files\wNurse\

User data (database, logs) stays under %LOCALAPPDATA%\wNurse\ and is not removed on uninstall or update.

System Requirements

  • OS: Windows 10 22H2 x64 (build 19045) or Windows 11 x64
  • Runtime: No separate Python or Node.js installation required on the user PC

Usage

  1. Open wNurse™ from the Start Menu.
  2. Maintain nurses, staffing, requests, and holidays for the target month.
  3. Generate a schedule on the schedule tab, then confirm or download a candidate.
  4. Optionally verify an uploaded Excel roster on the verify tab.

Version History

  • Initial release of wNurse™ for Windows x64
  • Local SQLite persistence for ward nurses, staffing rules, OFF requests, and holidays
  • Google OR-Tools CP-SAT schedule generation with four candidate profiles
  • Roster verification and Excel export / upload validation

wOPD™

Patent searching, INPADOC patent family visualization, and automated downloading of original patent PDFs and File Wrapper documents with OCR.

Overview

wOPD™ is a Windows desktop application for patent searching, patent family visualization, and downloading original patent PDFs and File Wrapper documents.

Features

  • Patent Search: Search using a single application, publication, or grant number from US, EP, KR, JP, or CN. Choose Application or Publication/Grant interpretation (default). For US numbers, confirmed USPTO records search by grant number when available, otherwise by publication number; unconfirmed records use the entered number. Legacy US application numbers are supported.
  • Patent Family Search: Automatically retrieve and organize worldwide patent family members and priority applications.
  • Patent Family Tree: Visualize relationships, filing dates, priority claims, patent status, and estimated expiration dates. Switch between the default By Year view and By Country view (US, EP, and other countries). Repeated links to later descendants appear once per branch entry. Ancestor paths to searched patents are highlighted. Zoom, copy, save as PNG, or open in a separate window.
  • Patent Status & Expiration: View patent status and estimated expiration dates for US, EP, KR, JP, and CN patents.
  • USPTO Assignment Information: View recorded assignment information for eligible US patents.
  • USPTO Maintenance Fees: Open USPTO maintenance-fee pages for granted US patents.
  • File Wrapper Download: Select, download, and merge prosecution documents from USPTO, EPO Register, and KOPD with US/EP filters. JP/CN documents include separate original and English versions when available.
  • Original Patent PDF Download: Download original patent PDFs from Google Patents.
  • Google Drive Upload: Optionally upload final PDF results to My Drive after signing in with a personal Google or permitted Google Workspace account.
  • Searchable PDF (OCR): Create searchable PDFs for supported File Wrapper, Priority, and original patent documents. Choose Performance priority (default) or Speed priority processing.
  • Citation Review: Select US (w Citation) to extract IDS, Related Cases, and PTO-892 references from bookmarked US File Wrapper forms. Review selected EP patents via European Patent Register even if File Wrapper download fails. Each side displays Preparing, Writing, Complete, or Failed.
  • Download Progress & Notifications: Monitor downloads and processing, cancel active work, and receive Windows notifications containing searched patent numbers even when focused.
  • Standalone Windows Application: Runs locally using Microsoft Edge WebView2 without requiring a separate web server or CDN connection.
  • Consistent Main-Window Layout: Keeps text, controls, and spacing at a consistent proportion of the default window across Windows text-size settings.

Installation & Location

Installed per-machine to the native 64-bit Program Files folder:

C:\Program Files\wOPD\

Creates a Start Menu shortcut and an optional Desktop shortcut. Application and OCR components are bundled. Microsoft Edge WebView2 Runtime is required and can be installed during setup. An internet connection is required for searches and downloads.

Requirements & Input

  • OS: Windows 10 or Windows 11 x64
  • Runtime: Microsoft Edge WebView2 Runtime (No separate Python installation required)
  • Google Account: Browser sign-in required only when Google Drive saving is selected
  • Supported Input: No file input is used; patent identifiers are entered directly as text

Usage

1. Search Patents
  • Enter a single patent application, publication, or grant number. Choose Application or Publication/Grant (default).
  • US application numbers can be entered with or without the US prefix (e.g., US09/004,827, 09/004,827, or 09004827).
  • Click Search to retrieve patent details and INPADOC family members.
  • File Wrapper lists are retrieved automatically from USPTO, EPO Register, and KOPD with status display and cancellation support.
2. Explore the Patent Family Tree
  • View relationships, priority claims, and filing histories. Select By Year or By Country. Copy uses the active view; Save outputs PNGs for both views.
  • Caption shows elapsed time and turns green when the tree and Google patent status lookup finish, or red with a short reason on failure.
  • Check patent status and estimated expiration dates for US, EP, KR, JP, and CN patents. Zoom, copy, save as PNG, or open in a separate window.
3. Select Patents and Documents
  • Select countries, patents, Priority documents, and original patent PDFs (unavailable items marked N/A).
  • Expand File Wrapper lists to select individual documents or use US/EP category presets.
4. Configure Download Options
  • Choose ascending or descending document date order and select a local destination folder.
  • Optionally enable Google Drive saving (complete sign-in via default browser; remains active until 인증취소 is selected).
  • US/EP File Wrapper and Priority OCR start checked. KR, JP, CN, and original patent OCR start unchecked.
  • Performance priority is the default OCR engine choice. Choose Speed priority for existing language-specific recognition.
  • US (w Citation) extracts citation texts: Performance priority reuses its OCR result; Speed priority applies multilingual recognition to citation bookmarks.
5. Download Documents
  • Click Download Selected Documents. On completion, Windows Explorer opens the output folder and 저장폴더 열기 appears in green (red if failed/cancelled).
  • File Wrapper documents merge into bookmarked PDFs; Priority documents save separately. JP/CN include original and English versions when available.
  • By Year and By Country Family Tree and US Assignment PNG snapshots are saved into the patent subfolder.
  • When Google Drive is enabled, final PDFs are uploaded after validation. PNG snapshots and citation Excel workbooks are not uploaded.
  • Review references in the Citations card tables. Selected EP patents are reviewed even if File Wrapper downloads fail, unless cancelled.
6. Monitor Progress & 7. Review Assignments / Fees
  • Monitor active downloads and processing across USPTO, EPO Register, KOPD, Google Patents, and Google Drive. USPTO card displays Citations step when US (w Citation) is active; EPO Register card displays Citations step for EP FW.
  • Cancel active downloads and receive Windows notifications containing the searched patent number (subsequent updates replace existing notices).
  • View USPTO assignment history and open maintenance-fee pages for eligible US patents.
  • Note: US provisional-only searches support USPTO File Wrapper retrieval and download, but not Family Tree or original patent PDF downloads.

Output Folder & Naming Rules

  • Default save location is the Windows Downloads folder. Merged PDFs and original PDFs are stored in a subfolder named after the searched patent number (US provisional-only downloads save directly to the root save folder / My Drive root).
  • Patent Family Tree and US Assignment snapshots are saved in the searched patent's subfolder.
  • Citation review outputs an Excel workbook ([Grant/PubNumber]_citations.xlsx) with enabled US/EP citation tables, bold light-green headers, and auto-fitted columns. Existing rows are preserved on failure.
  • Failed download error logs are saved in the selected folder; application logs stay under %LOCALAPPDATA%\wOPD_Downloader\logs.
Citations Excel: [Grant/PubNumber]_citations.xlsx
Family Tree PNG: …__Family_Tree_By_Year.png / …_By_Country.png
JP/CN FW Original: JP…__fw.pdf / CN…__fw.pdf
JP/CN FW English: JP…__fw__eng.pdf / CN…__fw__eng.pdf
Performance OCR: …__ocr_multi.pdf
Speed/Fallback OCR: {stem}__ocr_eng.pdf / …__ocr_kor+eng.pdf
Duplicates: Numbered (1), (2), etc.

Known Limitations

  • Patent searches and downloads depend on external services (EPO OPS, USPTO, EPO Register, KOPD, Google Patents). Access restrictions or service outages may prevent retrieval.
  • wOPD validates EPO OPS, USPTO, KOPD, Google Patents, and Google Drive authentication using bundled public CA certificates (CA-bundle environment variables do not override this). Enterprise proxies replacing certificates with private ones will trigger verification errors.
  • EP File Wrapper downloads require access to EPO Register and may require browser verification.
  • Ambiguous patent search results require user review and are not auto-selected.
  • Patent family, status, and expiration dates depend on Google Patents data and should not be treated as definitive legal status.
  • USPTO Assignment Information reflects recorded history and does not necessarily identify the current legal owner.
  • Google Drive upload uses drive.file scope limited to items created/opened by wOPD. Shared Drives and user-selected Drive folders are not supported. Use 인증취소 before uninstalling to revoke stored tokens.
  • Performance-priority OCR supports multiple languages in one model but does not recognize Korean. KR File Wrapper and KR original patent PDFs use the Korean-capable Speed-priority engine automatically. Sampled pages fall back when Korean is detected.
  • Speed-priority OCR supports English, Korean, Japanese, Chinese (Simplified), French, and German. Detection may be imperfect for mixed or low-quality scans.
  • Citation extraction requires matching File Wrapper bookmarks and supported USPTO form layouts. Missing bookmarks or unusual layouts may result in incomplete rows.
  • EP citation review depends on European Patent Register Citations pages. Access limits or layout changes may prevent retrieval.
  • OCR modifies digitally signed PDFs and invalidates cryptographic signatures. Only successful OCR replaces the file; failed OCR retains the signed original.
  • Missing or failed downloads/OCR are reported explicitly; KOPD items missing from the download store fail individually while valid siblings are saved.
  • OS or security software file notifications cannot be suppressed by wOPD.
  • On displays smaller than the default window, the window fits the usable area and scrolls.
