wooBundle™

Convert, merge, organize, and split PDF and Microsoft Office documents with Windows Explorer integration.

View Full Manual → Collapse Manual ↑

Overview

wooBundle™ is a Windows 10 22H2 x64 (build 19045) and Windows 11 x64 utility for converting, merging, organizing, and splitting PDF and Microsoft Office documents. The current application version is defined in src/woobundle/version.py.

Features

  • Merge PDF, Word, Excel, and PowerPoint files into one PDF Bundle
  • Convert selected Word, Excel, and PowerPoint documents into individual PDFs
  • Accept .zip selections: inspect metadata without extracting, then extract after Start into per-run temporary directory
  • Generate filename bookmarks and patent-file-wrapper bookmark colors
  • Choose Document Start Mode for merged Bundles: Continuous or Odd Page Start
  • Convert single selected PDF: detect FW from bookmark titles, report Natural Sort order, optionally reorder top-level page blocks, and apply FW coloring
  • Split single selected PDF at bookmark then page boundaries using Maximum Words per PDF limit
  • Name Splitter Parts as [OutputFilename]_PartN_pStart-End_chStart-End
  • Insert selectable-text summary page at start of each Splitter Part and remap Bookmarks after that page
  • Integrate with Windows Explorer legacy context menu for selected files
  • Integrate with Windows Explorer Send to menu for all users

Installation & Location

Installed per-machine to the native 64-bit Program Files folder:

C:\Program Files\wooBundle\

The installer creates/updates the Explorer context-menu entry (files only) and the all-users Send to shortcut.

Supported Input Extensions

  • PDF: .pdf
  • Word: .doc, .docx, .docm
  • Text/HTML: .txt, .rtf, .odt, .html, .htm, .mht
  • Excel: .xlsx, .xlsm
  • PowerPoint: .ppt, .pptx, .pptm, .pps, .ppsx, .ppsm
  • ZIP: .zip (selection container only)

Usage

  1. Select one or more supported files in Windows Explorer.
  2. Right-click and select wooBundle™ (on Windows 11, select Show more options when necessary). Alternatively, right-click and choose Send to → wooBundle™.
  3. Configure the input screen for the selection:
    • Two or more files, Merged Bundle: Output Mode, Bookmark Type, Filename Sort Order, Document Start Mode, Output Filename, Output Folder.
    • Two or more files, Individual PDFs: Output Mode and Output Folder.
    • Single non-PDF file: Output Filename and Output Folder only.
    • Single PDF, Converter: Processing Mode, Current Bookmark Order, Bookmark Sort Order, Output Filename, Output Folder.
    • Single PDF, Splitter: Processing Mode, Current Bookmark Order, Maximum Words per PDF, Output Filename, Output Folder.
  4. Select Start. ZIP members are extracted only after Start into a per-run temporary folder.

Output Naming Rules

Merged FW: [FolderName]__fw.pdf
Standard Merged: [FolderName].pdf
Blank Merged: wooBundle.pdf
Splitter Parts: [Output]_PartN_pStart-End_chStart-End.pdf

Known Limitations

  • All selected files must reside in the same folder.
  • Explorer context-menu processing supports at most 100 selected files (and at most 100 processing files after ZIP expansion).
  • Send to selection size is limited by the Windows command-line length.
  • ZIP files are not converted or merged as documents. Nested ZIPs, unreadable, encrypted, or unsafe ZIPs are rejected.
  • Password-protected PDFs requiring user credentials are not supported.
  • Legacy .xls and binary .xlsb workbooks, or workbooks with Excel 4.0 macro sheets, are rejected for safety.
  • Office documents are opened with macros disabled.

wooIEEE™

Group IEEE Mentor contribution files into searchable PDF Bundles with auto-generated TOC and Separators.

View Full Manual → Collapse Manual ↑

Overview

wooIEEE™ is a Windows 10 22H2 x64 (build 19045) and Windows 11 x64 utility that groups IEEE Mentor contribution files into searchable PDF Bundles with a generated Table of Contents, Separator pages, bookmarks, manifests, and error logs.

Features

  • Convert Word, Text/HTML, Excel, and PowerPoint files to PDF using Microsoft Office
  • Set Bundle Target Count on Home screen (default 30 for current run; unsaved)
  • Group documents by Standard and Year without splitting a DCN group
  • Generate A4 searchable TOC and Separator pages with bundled Unicode fonts
  • Title TOC as IEEE 802.{Standard} Contribution Bundle : {StartDCN} - {EndDCN}
  • Place TOC bookmark as first outline entry, with contribution bookmarks below
  • Create contribution bookmarks and full-row TOC links to each Separator
  • Allow only one wooIEEE instance per Windows user session

Installation & Launch

Installed per-machine to the native 64-bit Program Files folder:

C:\Program Files\wooIEEE\

The installer creates a Start Menu shortcut named wooIEEE™. It does not add an Explorer context-menu entry.

Filename Requirements

IEEE Mentor filenames must strictly follow the format:

[Standard]-[YY]-[DCN]-[REV]-[GROUP]-[TITLE].[EXT]

Corresponding Office desktop apps are required; no Python runtime needed.

Usage

  1. Start wooIEEE™ from the Start Menu.
  2. Confirm the Input Folder. The last Browse-selected folder is restored if present; otherwise Windows Downloads is used.
  3. Set Bundle Target Count if needed (defaults to 30; integer ≥ 1).
  4. Select Start.
  5. If unsupported files are detected, select Process only supported files or Cancel.
  6. After completion, click Open Folder to inspect generated outputs.

Output Folder & Naming Rules

Results are written to {InputFolder}\wooieee_output.

Bundle PDF: Bundle_[Standard]-[YY]-[StartDCN]-[EndDCN].pdf
Manifest CSV: Bundle_[Standard]-[YY]-[StartDCN]-[EndDCN]_manifest.csv

First collision uses (2), then (3), and so on for both PDF and manifest pairs.

Known Limitations

  • Existing outputs are auto-excluded only under immediate wooieee_output directory.
  • Password-protected PDFs requiring user credentials are not supported.
  • Office documents are opened with macros disabled and without Office-generated PDF bookmarks.
  • Characters that bundled Noto Sans / Noto Sans KR fonts cannot draw trigger a fatal error.
  • The installer does not force-terminate instances. Silent update/uninstall is unsupported if an instance is running.

  • PDF and Microsoft Office conversion
  • A4 TOC, Separator, bookmark, link, and manifest generation
  • Single-instance locking and installer graceful shutdown

  • TOC Generation Attribution footer with clickable project URL

Architecture & Python Standard Library

Low-level Office conversion and PDF primitives live in src/woocore and are statically bundled into each executable. The applications do not depend on each other.

Python Standard Library (Built-in)

tkinter / ttk is part of the Python Standard Library, not a pip dependency. Windowed builds embed the native Tcl/Tk runtime.

  • wooBundle: tkinter/ttk, zipfile, pathlib, tempfile
  • wooIEEE: tkinter/ttk, pathlib, tempfile
Shared Foundation (wooCore)

Provides unified Microsoft Office COM automation via pywin32, deterministic sorting, PDF structure validation, and per-run safe tempfile management.

Source: src/woocore (embedded per package)
